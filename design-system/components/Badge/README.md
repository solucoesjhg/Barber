# Badge

Selo de status, diferenciado só por opacidade e borda, nunca por cor. `<BarberOS.Badge status="confirmed">Confirmado</BarberOS.Badge>`. Classes `.badge-*` de `src/index.css`.

## Status
`pending` Pendente/Aberta · `confirmed` Confirmado (o mais forte) · `done` Concluído/Paga · `canceled` Cancelado/Vencida (borda tracejada).

## O que o consumidor fornece
O rótulo; o CSS põe em caixa alta.
