# Icon

Ícones lucide de traço fino usados no app. `<BarberOS.Icon name="calendar" size={16} />`. Herda a cor do texto (`currentColor`).

## Regras
`strokeWidth` 1.75 por padrão, 2.2 no item ativo da navegação, 2.5 no "+" do botão primário. Tamanhos 12–16px. Sempre em `text-muted` ou `text-faint`, nunca coloridos. Nomes disponíveis em `index.d.ts` (`IconName`); o app usa lucide-react completo.
